# 🧵 Textile Count & CV% Calculator

A simple and user-friendly Streamlit web application for textile calculations.

## Features

### Yarn Count Calculator
- Calculate English Count (Ne)
- Calculate Metric Count (Nm)
- Calculate Tex
- Calculate Denier
- Convert between different count systems

### CV% Calculator
- Enter multiple test readings
- Calculate Mean
- Calculate Standard Deviation
- Calculate CV%

## Formula

CV% = (Standard Deviation / Mean) × 100
